# generateSprite Documentation

## Brief Description
`generateSprite` is a function that generates a sprite sheet image based on a given description, using AI-powered image generation and analysis.

## Usage
To use `generateSprite`, import it from the `spriteAI` module and call it with a description of the character or environment you want to generate.

```javascript
import { generateCharacterSpritesheet, generateEnvironmentSprites } from './spriteAI';

// Generate a character spritesheet
const characterResult = await generateCharacterSpritesheet('a cute dragon', {
  states: ['idle', 'walk', 'run'],
  framesPerState: 4,
  size: '512x512',
  style: 'pixel-art',
  padding: 2,
  direction: 'left',
  save: true
});
console.log('Spritesheet generated:', characterResult.spritesheet);

// Generate an environment tileset
const environmentResult = await generateEnvironmentSprites('fantasy forest', {
  elements: 4,
  size: '1024x1024',
  style: 'pixel-art',
  padding: 1,
  theme: 'fantasy',
  save: true
});
console.log('Tileset generated:', environmentResult.tileset);
```

## Key Updates
- The `generateSprite` function has been split into two separate functions: `generateCharacterSpritesheet` and `generateEnvironmentSprites`.
- The `generateCharacterSpritesheet` function allows you to generate character spritesheets with customizable animation states and frames.
- The `generateEnvironmentSprites` function allows you to generate tilesets for game environments with various elements.
- New SDK functions have been added to fetch available animation states and sprite styles.
- The package now supports additional sprite styles, including vector, 3D, hand-drawn, and anime.
- The documentation has been updated to reflect these changes and provide more detailed usage examples.

## Parameters
- `generateCharacterSpritesheet`:
  - `description` (string, required): A text description of the character to generate.
  - `options` (object, optional):
    - `states` (array): List of animation states to include (default: `['idle', 'walk', 'run', 'attack']`).
    - `framesPerState` (number): Number of frames per animation state (default: `6`).
    - `size` (string): Size of the generated image (default: `'1024x1024'`).
    - `style` (string): Art style of the sprite (default: `'pixel-art'`, available: `['pixel-art', 'vector', '3d', 'hand-drawn', 'anime']`).
    - `padding` (number): Padding between frames (default: `1`).
    - `direction` (string): Direction the character faces (default: `'right'`).
    - `save` (boolean): Whether to save the generated image to disk (default: `false`).
- `generateEnvironmentSprites`:
  - `description` (string, required): A text description of the environment to generate.
  - `options` (object, optional):
    - `elements` (number): Number of environment elements to generate (default: `4`).
    - `size` (string): Size of the generated image (default: `'1024x1024'`).
    - `style` (string): Art style of the sprites (default: `'pixel-art'`, available: `['pixel-art', 'vector', '3d', 'hand-drawn', 'anime']`).
    - `padding` (number): Padding between elements (default: `1`).
    - `theme` (string): Theme of the environment (default: `'fantasy'`).
    - `save` (boolean): Whether to save the generated image to disk (default: `false`).

## Return Value
Both `generateCharacterSpritesheet` and `generateEnvironmentSprites` return an object with the following properties:
- `original`: The URL of the original image generated by DALL-E.
- `spritesheet` or `tileset`: A base64-encoded data URL of the generated sprite sheet or tileset.
- `metadata`: An object containing information about the generated image, such as the number of frames, frame dimensions, and other relevant data.

## Examples

## Notes or Considerations
- The functions use AI models (DALL-E 3 and GPT) to generate and analyze images, which may result in varying outputs for the same input.
- Generated sprites and tilesets are optimized for their respective use cases (character animations and game environments).
- The functions may take some time to complete due to API calls and image processing.
- When saving images, they are stored in an 'assets' folder with a filename based on the description.
